How to Play

Goal: Light up bulbs to build binary numbers! Each bulb has a value — ON bulbs add up.

Build levels: Flip switches so the lights add up to the target, then press Check.

Code Reader: Read the glowing pattern and type its number.

Lightning: Answer as many as you can before time runs out!

Secret Messages: Letters are numbers too! A = 65, B = 66… Decode glowing letters and write your own in ASCII code.

Stars: First try = ★★★. Stars unlock new worlds ({{UNLOCK_STARS}} needed).

Explorer mode keeps hints on all the time.
