# Burson Floor — FinComms HK

Pixel office life sim of the Burson FinComms team floor in Hong Kong.  
**People talk a lot.** Warm agency comedy, fictional lines, real seat map.

## Play

Double-click `index.html`, or:

```bash
# optional local server
npx --yes serve .
```

## Controls

| Input | Action |
|--------|--------|
| WASD / arrows | Move |
| Click floor | Walk there |
| Click person / **E** / Space | Talk or interact |
| **E** at your desk | Sit / stand (focus block) |
| **E** at coffee / water | Restore focus |
| 📋 | Tasks |
| 💬 | Chat density (chill / normal / chaotic) |
| 🔊 | Mute |

## Loop

1. Pick any named FinComms seat  
2. Walk the open plan, overhear bubbles & pair banter  
3. Chat with colleagues, grab coffee, sit for a focus block  
4. Day runs **09:00 → 18:00** (accelerated) → end-of-day recap  

## Stack

Vanilla HTML / CSS / JS · canvas pixel render · no build step  
Inspired by the same static-game approach as Amber’s Farm.

## Note

Names match the team seating chart for internal fun.  
Dialogue is **made up** — not real quotes, clients, or confidential work.
